# ToDo-лист «Доска задач»

Лабораторная работа №2 по веб-программированию - ToDo-лист в виде доски со стикерами.


## Возможности

- добавление задачи: название, срок и цвет стикера
- удаление задачи
- редактирование текста и даты прямо на стикере (Enter - сохранить, Esc - отмена)
- отметка "выполнено" - стикер блекнет, текст зачёркнут
- сортировка по дате (повторный клик - в обратную сторону, задачи без срока в конце)
- фильтр по статусу: все / невыполненные / выполненные
- поиск по названию без учёта регистра
- смена порядка перетаскиванием (drag-and-drop); на телефоне - кнопки ↑ ↓
- задачи сохраняются в localStorage и восстанавливаются после перезагрузки
- просроченные задачи подсвечиваются красным, в шапке счётчик "Выполнено N из M"
- адаптивная вёрстка: компьютер, планшет, телефон

## Питомец

Внизу экрана гуляет питомец с бензопилой:

- обычно идёт вприпрыжку: стоит - прыгает - стоит - прыгает
- у края экрана разворачивается и идёт обратно
- при добавлении задачи подпрыгивает с сердечком, а потом 5 секунд ходит накачанным
- не мешает кликам и скрывается, если в системе включено "уменьшить движение"

Анимация покадровая: каждые 0,3 с JS меняет картинку (`setInterval`).
Движение по экрану, разворот и прыжок - CSS `@keyframes`.

## Как выполнены требования

| Требование | Как сделано |
|---|---|
| В HTML только каркас и скрипт | `index.html` — `<script src="main.js">`, CSS подключается из JS |
| Элементы создаются через JS, семантические теги | функция `createEl()`; `header`, `main`, `section`, `form`, `fieldset`, `ul`/`li`, `time`, `footer` |
| Текст, атрибуты, стили через JS | `textContent`, `className`, `classList`, `setAttribute`, `type`, `placeholder` |
| Сборка через методы DOM | `append`, `replaceChildren`; `innerHTML` не используется |
| Адаптивность | grid для доски, flex для форм, `@media` в `style.css` |
| Добавление и удаление | `addTask`, `deleteTask` |
| Редактирование текста и даты | `startEdit`, `updateTask` |
| Отметка "выполнено" | `toggleDone` + класс `sticker--done` |
| Сортировка по дате | `sortByDate` |
| Фильтр по статусу и поиск | `getVisibleTasks` |
| localStorage | `saveTasks`, `loadTasks` (JSON) |
| Drag-and-drop | `addDragAndDrop`, `moveTask`; кнопки ↑ ↓ — `moveByStep` |


## Как запустить

Открыть `index.html` в браузере - сборка не нужна.
